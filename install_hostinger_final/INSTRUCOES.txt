INSTRUÇÕES DE INSTALAÇÃO - MAISDEUS.COM (Bíblia Acontecendo Agora)
================================================================

1. PREPARAÇÃO DO BANCO DE DADOS
   - Acesse o painel da Hostinger -> Banco de Dados -> Criar Novo Banco de Dados MySQL.
   - Anote: Nome do Banco, Usuário e Senha.

2. IMPORTAÇÃO DOS DADOS (phpMyAdmin)
   - Vá na aba "Importar" e envie os arquivos NA SEGUINTE ORDEM:
     1º: database.sql (Cria a estrutura)
     2º: O SEU ARQUIVO DE VERSÕES (biblia_13V.sql)
     3º: api/seed_enrichment.sql (Dados de demonstração para Gênesis e Êxodo)

3. CONFIGURAÇÃO (api/db.php)
   - Abra a pasta `api` e edite o arquivo `db.php`.
   - Coloque os dados do banco que você criou no passo 1.

4. UPLOAD
   - Suba TODOS os arquivos e pastas deste ZIP para dentro da pasta `public_html` na Hostinger.
   - O arquivo `index.html` deve ficar direto dentro de `public_html`.

PRONTO! O site deve abrir com as 13 versões listadas e a funcionalidade "Bíblia Acontecendo Agora" ativa em Gênesis 1.
